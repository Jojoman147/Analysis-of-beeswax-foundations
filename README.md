# Analysys-of-beeswax-foundations (AOBF)


This set of scripts has been designed to contain all the necessary tools for successfully analysing the structure of intercellular walls.
The first script, AOBF, is designed to read and process data from an image file, while the scripts AOBF statystic.py and AOBF statistics 2.py are designed to visualise the analysis results in graphs.
The first published version of the codes (1.0) has been annotated in Slovak to make them easily understandable for Slovak users.
Next versions of the codes will be published in English to make them accessible to a wider audience.
